Why small singular values amplify noise

In the SVD bases, least squares is just division: split b along the ui, divide piece i by σi, reassemble along the vi. Noise in b gets divided the same way, so noise along a direction with a small σ comes out huge. Make the columns of A more nearly parallel and watch it happen.

A cloud of noisy solutions

The exact data b = A(1, 1) is disturbed by random noise of size ε in each entry, 300 times, and each time we solve the least-squares problem. Each dot is one solution’s error x − (1, 1).

v1 directionv2 directionpredicted spread (2 ε/σi each way)

Noise of size ε along ui moves the solution by ε/σi along vi. So the cloud is an ellipse with half-axes proportional to 1/σ1 and 1/σ2, and the ratio of its axes is σ1/σ2 = cond(A). The normal equations would divide by σi2 instead, which is why cond(ATA) = cond(A)2.
